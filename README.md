#  Taekwondo Kick Meter

An IoT-based Taekwondo performance monitoring system that measures **kick force, speed, and pressure distribution** using embedded sensors and provides real-time training data through a web dashboard.

The system combines an **Arduino Nano 33 IoT, Raspberry Pi, load cell, FSR sensors, BLE communication, Firebase, and a React dashboard** to collect, process, store, and visualize training data.

> **Academic Project — SIT210 Embedded Systems Development**

---

##  Overview

The Taekwondo Kick Meter was developed to provide objective performance feedback during Taekwondo training.

Traditional training often relies heavily on subjective observation. This system uses embedded sensors to capture measurable information such as:

* Kick force
* Kick speed
* Pressure distribution
* Training-session statistics
* Performance trends

The collected sensor data is transmitted through a BLE-to-Raspberry-Pi pipeline, processed, stored in Firebase, and displayed through a React-based dashboard.

##  Key Features

###  Kick Force Measurement

Uses a load cell and HX711 amplifier to capture the force generated by a kick.

###  Kick Speed Estimation

IMU sensor data is used to estimate movement and kick speed.

###  Pressure Distribution

Multiple FSR sensors provide pressure information across different regions of the target.

###  Wireless Communication

Sensor data is transmitted from the Arduino to the Raspberry Pi using Bluetooth Low Energy.

###  Real-Time Dashboard

A React dashboard provides a visual representation of collected training data.

###  Cloud Data Storage

Firebase is used to store and retrieve training-session data.

###  Training Analytics

The system allows performance measurements to be reviewed across training sessions.

##  Data Pipeline

```text
Sensors
   ↓
Arduino Nano 33 IoT
   ↓
BLE
   ↓
Raspberry Pi
   ↓
Python Processing
   ↓
Firebase
   ↓
React Dashboard
```

The Raspberry Pi acts as the central processing and aggregation layer, receiving sensor data, processing it, and forwarding the resulting data to Firebase.

##  Challenges

During development, several practical issues were encountered, including:

* Sensor calibration and inconsistent readings
* BLE communication reliability
* Noise in sensor measurements
* Synchronization of multiple sensor inputs
* Data processing and aggregation
* Hardware/software integration

The project involved iterative testing and calibration to improve the reliability of the measurements.
